---
title: "Search and retrieve contacts"
---
V3 acquires and returns contacts in a single billable POST request. Previewing first is optional.

1. Choose `agents` or `brokerages` and the dashboard-compatible filters.
2. Optionally count matches or preview availability and estimated credits.
3. Save a UUID and submit search with `max_credits`.
4. Consume the returned contact records and save the request receipt.
5. Follow `next_cursor` for additional pages, using a new key per page.

Use lookup with IDs returned by preview/search to retrieve an exact selection, including records not previously owned. `missing_ids` includes unavailable, contactless and suppressed IDs without revealing the reason. No missing ID is charged.

Every field available for the selected record is returned; there is no separate per-field fee. Contact fields are format-checked only. Preserve `location_source` attribution when using source-derived addresses, cities or ZIP codes.

Legacy v2 unlock remains documented in the v2 API reference.
