---
title: "Export contacts"
---
Submit `POST /api/v3/exports` with a UUID `Idempotency-Key`, `kind`, filters or IDs, `limit`, `max_credits`, and `format` (csv or json).

```json
{"kind":"brokerages","filters":{"state":"CA","orgType":"brokerage"},"limit":1000,"max_credits":2000,"format":"csv","template":"hubspot"}
```

The 202 response includes `export_id`, `request_id`, `snapshot_id`, and `selected_records`. Selection freezes at creation. Credits are checked and settled when the result is durably prepared; no credits are held while queued.

Poll `GET /exports/{id}`. Once ready, download with `GET /exports/{id}/download` and the same account's API key. Downloads never acquire additional contacts. Cancel queued work with `POST /exports/{id}/cancel`; completed preparation cannot be cancelled.

CSV templates: standard, hubspot, salesforce, follow_up_boss, apollo and instantly. These are import formats, not live integrations. All include required location attribution and spreadsheet-safe escaping.

Jobs expire if preparation has not started within 24 hours, retry transient failures up to eight attempts, and fail without acquisition if credits are insufficient or the cap is exceeded. Results expire 30 days after preparation. Later suppressions apply to JSON and CSV downloads.

The deployment must enable the protected export cron. Local development requires explicitly invoking the worker; running the dev server alone does not process jobs.

Status record_count reports records prepared originally; later suppressions can reduce download rows.
