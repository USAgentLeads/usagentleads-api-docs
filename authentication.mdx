---
title: "Authentication"
---
Use `Authorization: Bearer YOUR_API_KEY` or `X-API-Key: YOUR_API_KEY`. Create, revoke and rotate keys in the dashboard. Never put keys in query strings, source code, logs, generated CSVs or MCP prompts.

Growth and Pro can use all v3 endpoints and hosted MCP. Coverage and location suggestions also support unauthenticated requests. The account behind the key determines ownership, credit balance, quotas, suppressions and request recovery; client-supplied user IDs are rejected.

Billable POST requests require a UUID `Idempotency-Key` header and an explicit `max_credits` body value. MCP uses `idempotency_key`, `max_credits` and `confirm_credit_spend: true`.
