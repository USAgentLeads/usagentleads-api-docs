---
title: "USAgentLeads API"
description: "Find agents and brokerages and receive their available contact details directly."
---

API v3 provides the same geographic, availability, organization and audience filters as the dashboard. Search returns contact records directly; there is no separate unlock prerequisite.

<Note>API v3 is available for Growth and Pro accounts.</Note>

Growth and Pro include REST v3 and hosted MCP. New agent records cost one credit; new brokerage records cost two. Contacts already acquired in the dashboard, REST or MCP cost zero on repeat access.

Start with [the quickstart](/quickstart), or browse the separate agent and brokerage endpoint references. Count and preview are optional, free discovery steps. All requests are rate-limited.

The catalog is a dated snapshot. Contact presence means format-checked data, not confirmed deliverability, current licensing, a direct mobile line or permission to contact someone.
