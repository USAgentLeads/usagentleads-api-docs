---
title: "Quickstart"
description: "Preview an audience before spending credits."
---

1. [Sign in](https://www.usagentleads.com/login?next=%2Fdashboard%2Fapi-keys) using Google or an email magic link.
2. API v2 read access requires Growth, Pro, or an existing Pro API subscription. API unlocks and MCP require Pro. Self-service selection of new plans will arrive with the updated dashboard; [contact support](https://www.usagentleads.com/contact) for account setup during the rollout.
3. Create an API key in [API settings](https://www.usagentleads.com/dashboard/api-keys). Copy it once and store it in an environment variable.

```bash
export USAGENTLEADS_API_KEY='your-key'
curl --fail-with-body https://www.usagentleads.com/api/v2/search/preview \
  -H "Authorization: Bearer $USAGENTLEADS_API_KEY" \
  -H 'Content-Type: application/json' \
  --data '{"kind":"agents","filters":{"state":"CA","mustHave":["email"]}}'
```

The result includes `releaseId`, total and field counts, and masked rows with release-scoped `ordinal` identifiers. A preview does not spend record credits. Follow [the unlock workflow](/workflows/unlock) only after confirming the audience and maximum spend.
