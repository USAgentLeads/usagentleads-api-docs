---
title: "MCP"
---
Hosted Streamable HTTP endpoint: `https://www.usagentleads.com/api/mcp`. Growth and Pro use the same account credits, ownership and request limits as REST.

Configure a compatible client with this URL and an `Authorization: Bearer` header from a protected environment variable. Never embed credentials in a shared URL or prompt.

New tools include `search_agents`, `search_brokerages`, `lookup_agents`, `lookup_brokerages`, audience count/preview tools, `get_account`, `get_usage`, `get_request`, `search_locations`, `create_contact_export`, `export_status`, `export_download` and `cancel_export`.

Billable tools require `max_credits`, a saved UUID `idempotency_key`, and `confirm_credit_spend: true`. Obtain the user's approval for the selection and maximum spend before setting confirmation. Retrying must preserve the same key and arguments. `export_download` returns an authenticated download URL; it never places the API key in that URL.

The stdio package uses the same generated tool schemas and maps all 16 tools to REST v3. The hosted transport accepts POST; GET and DELETE return 405.
